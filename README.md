# Mecanismo_Laplace
<br>
En este repositorio encontraremos unos pequeños ejemplos para el trabajo final la asignatura TENDENCIAS EMERGENTES EN SEGURIDAD DE DATOS del Máster Universitario en Inteligencia de Negocio y Big Data en Entornos Seguros (UVa,UBu,ULe).
<br>

Un hospital tiene dos bases de datos vecinas D(65 pacientes con asma) y D'(64 pacientes con asma) que difieren en un único paciente.
<br>

Podemos encontrar un archivo python "privacidad_diferencial.py" en el que calculamoos el nivel de privacidad en las dos librerías diffprivlib y OpenDP y comparamos los resultados.
<br>

Podemos encontrar también un Jupyter "privacidad_epsilon.ipynb" en el que vemos la relación entre el nivel de privacidad (epsilon) y la exactitud de los resultados.
